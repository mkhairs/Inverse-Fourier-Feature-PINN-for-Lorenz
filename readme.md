# Overview: Fourier-Feature FPINN for the Lorenz System

This notebook uses an **inverse Physics-Informed Neural Network (FPINN)** with Fourier features to estimate the Lorenz system's state variables and parameters from noisy synthetic data.

The Lorenz equations are:

$$
\frac{dx}{dt}=\sigma(y-x),\quad
\frac{dy}{dt}=x(\rho-z)-y,\quad
\frac{dz}{dt}=xy-\beta z.
$$

Fourier features enrich the time input with sinusoidal functions, helping the network represent complex trajectories. The model combines these features with gated residual blocks and a trainable global skip connection.

Synthetic data are generated by numerically solving the equations. Training combines three losses: **data loss** for fitting observations, **physics loss** for enforcing the differential equations, and **initial-condition loss** for matching the starting state.

The model is trained using **AdamW**, followed by **L-BFGS** refinement. Results are assessed by comparing estimated parameters, predicted trajectories, prediction errors, and physics residuals with the reference solution.

**Goal:** evaluate whether Fourier-feature FPINN can recover Lorenz-system parameters and trajectories from noisy, partially observed data.
