# Overview: Inverse Fourier-Feature Physics-Informed Neural Network for the Lorenz System

## 1. Project Overview

This notebook implements an **Inverse Fourier-Feature Physics-Informed Neural Network (Inverse FPINN)** to model the Lorenz system and estimate its unknown physical parameters from synthetic observations. The model approximates the three state variables, \(x(t)\), \(y(t)\), and \(z(t)\), while simultaneously learning the parameters \(\sigma\), \(\rho\), and \(\beta\).

Unlike a conventional data-only neural network, the FPINN incorporates the governing differential equations into its training objective. This physics-based constraint encourages predictions to fit the observed data while remaining consistent with the Lorenz dynamics.

## 2. Governing Equations

The Lorenz system is described by the following nonlinear ordinary differential equations:

\[
\frac{dx}{dt}=\sigma(y-x),
\]

\[
\frac{dy}{dt}=x(\rho-z)-y,
\]

\[
\frac{dz}{dt}=xy-\beta z.
\]

Here, \(x(t)\), \(y(t)\), and \(z(t)\) are the state variables. The parameters \(\sigma\), \(\rho\), and \(\beta\) determine the system's dynamics.

This is an **inverse problem**: the reference parameters are used to generate synthetic data, but the neural network starts from different initial parameter guesses and learns estimates during training.

## 3. Role of Fourier Features

Fourier features transform the normalized time input into a richer representation using sinusoidal functions. This gives the neural network access to multiple frequency components and can help it represent complex, rapidly changing patterns in the Lorenz trajectories.

In this notebook, Fourier features are part of the model backbone and are combined with gated residual blocks and a trainable global skip connection. Fourier features are a representation strategy; the physics residual and observation losses provide the main training constraints.

## 4. Model Architecture

The network combines three principal components:

- **Fourier-feature encoding:** enriches the time input with sinusoidal features.
- **Gated residual blocks:** use learnable gates to control the contribution of residual transformations.
- **Trainable global skip connection:** allows an initial representation to contribute directly to a later part of the network.

The model predicts \(x(t)\), \(y(t)\), and \(z(t)\), and includes trainable estimates of \(\sigma\), \(\rho\), and \(\beta\).

## 5. Data Generation and Preparation

Reference trajectories are generated by numerically solving the Lorenz equations with `scipy.integrate.solve_ivp`. The notebook uses the initial condition

\[
(x_0,y_0,z_0)=(1,1,1)
\]

and a simulation interval from \(t=0\) to \(t=50\), sampled at 1,000 time points. The reference parameters are \(\sigma=10\), \(\rho=28\), and \(\beta=8/3\).

The workflow then:

1. normalizes time to the interval \([0,1]\);
2. randomly selects a subset of observations for training and retains the remaining points for testing;
3. adds Gaussian noise to the training observations;
4. creates collocation points over the normalized time domain for evaluating the differential-equation residuals.

The notebook's configuration sets the training fraction to 50%, corresponding to 500 training observations out of 1,000 points. Check the configuration and explanatory text together if modifying the experiment, because some prose descriptions may not exactly match the current code values.

## 6. Training Objective

The total objective combines data fit, physics consistency, and the initial condition:

\[
\mathcal{L}
=w_d\mathcal{L}_{data}
+w_p\mathcal{L}_{physics}
+w_{IC}\mathcal{L}_{IC}.
\]

- **Data loss** measures the mismatch between model predictions and the noisy training observations.
- **Physics loss** penalizes violations of the Lorenz differential equations at collocation points.
- **Initial-condition loss** encourages the predicted initial state to match \((1,1,1)\).

Because the network uses normalized time, derivatives with respect to normalized time must be converted consistently to derivatives with respect to physical time when computing the physics residual.

## 7. Optimization Procedure

Training is carried out in two stages:

1. **AdamW:** performs the main optimization using minibatches of collocation points.
2. **L-BFGS:** refines the learned solution using a quasi-Newton optimization procedure.

Training diagnostics track the loss components, estimated physical parameters, the global skip coefficient, and the mean gates of the residual blocks.

## 8. Evaluation and Diagnostics

The notebook evaluates the model using several complementary views:

- estimated values of \(\sigma\), \(\rho\), and \(\beta\) compared with their reference values;
- training-loss curves;
- parameter evolution during optimization;
- global-skip and gate evolution;
- predicted state trajectories compared with reference trajectories and noisy observations;
- absolute prediction error over time;
- a three-dimensional comparison of the Lorenz attractor;
- physics residuals and their root-mean-square error (RMSE).

No single diagnostic is sufficient on its own. In particular, the Lorenz system is chaotic: small differences in states or parameters may lead to substantial trajectory divergence over long time intervals. Parameter estimates, physics residuals, and trajectory plots should therefore be interpreted together.

This project explores whether an inverse FPINN with Fourier features can recover the parameters and state trajectories of the Lorenz system from noisy, partially observed synthetic data.
